Non-negotiable boundary

Approval is not payment.

An authorized proposal is an integrity-checked local record that demo reviewers accepted an exact intent. It is never a command to a bank, PSP, UPI application, wallet, or payment rail.

Checking runtime boundary…
  • ✓
    No execution endpoint

    The public API contains no route that can pay, transfer, collect, debit, or dispatch.

  • ✓
    Opaque references only

    Payment addresses and account credentials do not belong in proposals.

  • ✓
    Mock observations are labelled

    Simulation exercises state handling; it never claims a real-world settlement.

  • ✓
    Every decision is auditable

    A hash-linked event trail exposes changes and supports integrity checks.
